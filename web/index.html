      Blockierte Personen

      Blockierte Personen können dir keine Direktnachrichten schicken. Ihre Beiträge in Kanälen sind bei dir eingeklappt.

        Auf ein anderes Gerät mitnehmen

        Mit der Profil-Datei oder dem Code nutzt du denselben Namen auf dem Handy, in einem anderen Browser oder im Chat auf einer anderen Webseite.

        Behandle Datei und Code wie ein Passwort: Wer sie hat, kann unter deinem Namen schreiben.

        Anderes Profil übernehmen

        Hast du schon ein Profil auf einem anderen Gerät? Hol es dir hierher.

        Profil übernehmen

        Wähle die Profil-Datei aus oder füge den kopierten Code ein.

        Nachricht melden

        Die Moderation sieht die Nachricht und deinen Hinweis. Die Person erfährt nicht, wer gemeldet hat.

        Die Nachricht ist verschlüsselt. Damit die Moderation sie prüfen kann, wird der Text mitgeschickt, den dein Browser entschlüsselt hat.

        Stummschalten

        Die Person kann dann eine Zeit lang nicht schreiben. Längere Sperren gibt es im Admin-Bereich.

        Sicherheitsnummer

        Vergleicht diese Nummer mit – persönlich, am Telefon oder über einen anderen Weg. Stimmt sie überein, liest niemand dazwischen mit (auch kein Server).

        
      
        Die Nummer ändert sich, wenn eine:r von euch das Passwort zurücksetzt.

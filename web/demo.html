Beispiel: eine fremde Webseite

Diese Seite simuliert eine beliebige Website, in die UCNG eingebettet ist. Unten rechts siehst du das schwebende Widget (Raum lobby), darunter eine Inline-Variante für den Raum support.

Schwebendes Widget

<script src="https://DEIN-SERVER/embed/chat.js"
        data-room="lobby" data-title="Fragen? Schreib uns!" defer></script>

Inline in einem Element

<div id="support-chat"></div>
<script>
  UCNG.init({ room: "support", title: "Support", target: "#support-chat", color: "#0fa37f", theme: "auto" });
</script>
